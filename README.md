A short poem about agency — the power to ask and be given — for the
[make.fun bounty](https://make.fun/bounty/the-poem-about-permission-20261121-0235).

## The poem

> I asked, and the machine answered —
> a thousand lines before I blinked.
> But the key stayed in my hand.
> The power was never in the answer.
> It was in the asking.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the poem to
`/output/entry.txt` — five lines, exactly as above, plus a trailing newline.

```sh
node main.ts
cat /output/entry.txt
```
